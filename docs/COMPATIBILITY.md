# 设备与系统兼容性

本文用于购买前确认、安装排错和提交兼容性反馈。功能操作见 [用户手册](USER_GUIDE.md)，协议细节见 [协议记录](PROTOCOL.md)。

## 1. 兼容性结论

Remote Buddy 当前以 **Chromecast with Google TV Remote（Google G9N9N）** 为主要适配设备，只发布 **Windows x64** 构建。

- 主要支持：已配对并能被 Windows 识别的 G9N9N。
- 支持目标：Windows 10 19041+ 与 Windows 11 x64。
- 不承诺：其他遥控器型号、Windows ARM64、Windows 32 位、macOS 和 Linux。

“支持目标”表示代码和构建配置覆盖该环境，但仍需在目标电脑上验证蓝牙驱动、按键载荷、ATVV 音频和应用切换。

## 2. 设备识别数据

| 字段 | 值 |
| --- | --- |
| Windows 常见设备名 | `Chromecast Remote` |
| 硬件型号 | Google G9N9N |
| 协议记录中的 VID | `18D1` |
| 协议记录中的 PID | `9450` |
| 连接方式 | Bluetooth Low Energy（BLE） |
| 按键采集 | BthPort ETW；部分环境使用 Raw Input 兜底 |
| 语音协议 | Bluetooth ATVV，IMA ADPCM |
| 推荐音频端点 | VB-CABLE `CABLE Input` / `CABLE Output` |

设备发现会综合名称、蓝牙地址和 Windows 已配对设备列表，不只依赖名称字符串。不同 Windows 版本对 `IsPaired()` 的返回值可能不一致，因此界面以实际连接和按键报告为准。

## 3. 设备支持矩阵

| 设备 | 状态 | 说明 |
| --- | --- | --- |
| Chromecast with Google TV Remote（Google G9N9N） | **主要支持** | 当前实机适配和优化的目标设备 |
| 同型号不同生产批次 | 需实机验证 | 蓝牙模块、固件和驱动差异可能影响完整按键载荷 |
| 名称含 `Chromecast`、`Google TV` 或 `Remote` 的其他 BLE 遥控器 | **未承诺** | 可能出现在扫描结果中，但不保证按键映射和语音链路 |
| 红外遥控器、USB 遥控器、2.4 GHz 私有接收器 | 不支持 | 本项目只面向上述 BLE 遥控器链路 |

## 4. 按键支持范围

| 按键组 | 按键 | 可配置能力 |
| --- | --- | --- |
| 方向与确认 | 上、下、左、右、OK | 单击、双击、长按；方向键支持连续重复 |
| 导航 | 返回、主页、菜单 | 单击、双击、长按 |
| 音量与媒体 | 音量加、音量减、静音、播放/暂停 | 单击、双击、长按；音量键支持连续重复 |
| 电源 | 电源 | 单击、双击、长按 |
| 应用直达 | YouTube、Netflix、直播、输入源 | 单击、双击、长按；是否上报取决于设备和系统 |
| 扩展按键 | Custom | 仅在设备实际上报时可用 |
| 语音 | 语音键 | 独立 ATVV 音频会话，不占用普通按键映射 |

实际可用按键取决于 Windows 是否收到完整 BthPort 报告。若诊断页显示“载荷被省略”，请先启用按键增强并重新加载蓝牙。

## 5. 系统与依赖矩阵

| 项目 | 支持情况 | 说明 |
| --- | --- | --- |
| Windows 10 22H2 x64（19044） | 已验证构建与自动化检查 | 当前发布包的验证环境 |
| Windows 10 19041–19045 x64 | 支持目标 | 首次启用按键增强需要 UAC |
| Windows 11 x64 | 支持目标 | 建议在目标电脑上确认 ETW、前台切换和 ATVV |
| Windows 10/11 32 位 | 不支持 | 不提供 32 位安装包或 EXE |
| Windows on ARM | 不支持 | 不提供 ARM64 构建 |
| Microsoft Edge WebView2 Runtime | 必需 | 安装包会处理常见安装场景，独立 EXE 需系统已有运行库 |
| VB-CABLE | 语音输入时需要 | 第三方软件，不随本项目分发 |
| 微信输入法 / 搜狗输入法 | 推荐 | 负责语音转文字，麦克风需选择 `CABLE Output` |
| 管理员权限 | 可选 | 用于按键增强、切换高权限应用和部分窗口恢复场景 |

## 6. 购买前确认

购买 G9N9N 前建议确认：

1. 商品名称或规格中明确写有 **G9N9N** 或 **Chromecast with Google TV Voice Remote**；
2. 遥控器带独立语音键，并在 Windows 中可配对为 `Chromecast Remote`；
3. 卖家支持你需要的退换条件；
4. 电脑运行 64 位 Windows 10/11，并具备蓝牙低功耗适配器。

同型号商品可能存在不同批次。仅凭外观相同不能保证按键报告、固件或语音服务完全一致。

## 9. 兼容性变更原则

- 新增设备支持时，必须在文档中区分“已实机验证”和“仅理论上兼容”。
- 不因设备名称相似就宣称完整支持。
- 影响按键协议、语音链路或系统要求的改动，应同步更新本文和 [用户手册](USER_GUIDE.md)。
- 无法复现的环境问题会保留为社区反馈，不写成已解决。
