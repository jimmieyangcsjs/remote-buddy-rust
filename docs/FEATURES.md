# 功能说明

本文说明 Remote Buddy 当前版本已经实现的功能、交互方式和边界条件。安装与配置步骤见 [用户手册](USER_GUIDE.md)。

## 1. 设计目标

Remote Buddy 不是传统意义上的 HID 重映射工具，而是一个把 **Chromecast with Google TV 遥控器**接入 Windows 桌面工作流的本地桥接程序。

设计目标：

- 设备连接与窗口显示解耦，最小化或关闭到托盘后仍保持连接；
- 普通按键、语音链路、系统动作彼此隔离，单条链路失败不会伪装成正常；
- 将遥控器按键映射为桌面应用真正可用的动作，而不只是媒体键；
- 所有配置、音频处理和日志都留在本机；
- 保留可测试的 Rust 领域层，便于后续增加新设备和动作类型。

## 2. 设备发现与连接

### 2.1 自动导入

启动后，程序读取 Windows 已配对 BLE 设备列表，按以下特征筛选受支持的遥控器：

- 设备名称包含 `Chromecast`、`Google TV`、`G9N9N` 或 `Remote`；
- 能取得有效蓝牙地址；
- 设备由 Windows 已配对设备选择器返回。

程序不依赖 `Pairing().IsPaired()` 的单一返回值，因为部分 Windows 版本会在设备实际可用时仍返回 `false`。

### 2.2 自动连接与重连

设备监督器维护目标设备、当前连接和重试状态：

- 启动后自动尝试上次选择的设备；
- 连接成功后由 Windows GATT 保活，不再周期性断开重连或探测 GATT；
- 首次连接失败停止自动重试，稳定连接意外断开后最多执行一次受控恢复；
- 用户主动点击“断开”后不自动恢复，必须手动重新连接；
- 切换设备会取消旧连接任务，避免两个会话同时写配置或争用输入源。

连接状态包括 `connecting`、`ready`、`disconnected` 和 `degraded`。只有底层会话确实可用时，界面才显示为已连接。

### 2.3 多设备配置

每个遥控器拥有独立的：

- 按键映射；
- 语音模式；
- 音频增益；
- 蓝牙地址和容器信息。

同一台电脑可以保存多台受支持遥控器，但任一时刻只处理当前选择设备的主要会话。

## 3. 虚拟遥控器与实时联动

总览页和按键映射页都使用按 G9N9N 外观绘制的 SVG 遥控器。

实体按键按下时：

1. BthPort ETW 或 Raw Input 产生按键报告；
2. 输入路由器识别按键和手势；
3. 虚拟遥控器对应按键高亮并下沉；
4. 总览事件区记录按键、手势、动作和输入来源；
5. 托盘菜单同步显示最近按键动作。

松开后按键恢复。方向键和音量键在按住时可按配置连续重复。

## 4. 按键映射

### 4.1 支持的手势

每个普通按键可以分别设置三种互斥手势：

| 手势 | 行为 |
| --- | --- |
| 单击 | 双击设置为“无动作”时立即触发；否则等待约 350 ms 的双击判定窗口 |
| 双击 | 在约 350 ms 内按下两次 |
| 长按 | 按住约 700 ms 后触发；可选择单次触发或按住保持 |

### 4.2 长按模式

长按有两种模式：

| 模式 | 适用场景 | 行为 |
| --- | --- | --- |
| 约 700 ms 触发一次 | 应用快捷键、普通按钮 | 达到阈值后发送一次动作，继续按住不重复 |
| 按住保持，松开释放 | 对讲、游戏、需要持续按下的快捷键 | 达到阈值后发送按键按下，直到遥控器按键松开才发送抬起 |

选择“按住保持”时，快捷键中的修饰键、普通键和媒体键会成对处理，避免出现按键卡住。

### 4.3 连续重复

方向键和音量键支持 `ContinuousRepeat` 动作，可设置重复间隔。它适合：

- 遥控器方向键连续移动光标；
- 长按音量键连续调整系统音量；
- 在允许连续输入的列表中快速滚动。

连续重复与“按住保持”不是同一概念：

- 连续重复会多次执行动作；
- 按住保持只发送一次按下，直到松开才释放。

### 4.4 动作类型

| 动作 | 说明 |
| --- | --- |
| 无动作 | 不执行系统动作，但仍可在实时事件中看到按键 |
| 快捷键 | 发送组合键或单键，例如 `Ctrl+Shift+F8`、`Alt+Tab`、`MediaPlayPause` |
| 文本 | 将预设字符串发送到当前前台窗口 |
| 媒体键 | 音量加、音量减、静音、播放/暂停 |
| 切换应用 | 激活指定应用窗口；未运行时启动填写的 EXE |
| 连续重复 | 按指定间隔重复当前动作 |

快捷键输入框支持直接按键录制，不需要手写语法。录制的组合键会规范化保存，并在总览、映射和语音相关页面共享同一份配置。

### 4.5 保存语义

点击“保存映射”后，新动作立即写入本机配置并更新运行时映射表。后续按键使用新配置，不要求重启应用。

“恢复默认”只重置当前遥控器的按键映射，不会删除设备配对、语音端点或程序设置。

## 5. 切换应用

### 5.1 选择方式

在映射动作中选择“切换应用”后，可以：

- 从当前可见的 Windows 应用窗口列表中选择；
- 手动填写目标 EXE 的完整路径；
- 为动作保留可读名称，方便识别。

程序只枚举本机可见顶层窗口，不读取窗口正文内容，也不上传窗口标题。

### 5.2 行为

激活目标应用时：

1. 按 EXE 路径匹配已有窗口；
2. 如果窗口最小化，则恢复；
3. 如果窗口已最大化，则保持最大化状态；
4. 将目标窗口切到前台；
5. 如果没有找到窗口但 EXE 存在，则启动应用。

针对 Magpie 等置顶覆盖窗口，当前实现会同时处理前台线程和目标线程，并在系统拒绝普通前台切换时使用受控的解锁与兜底路径。切换以管理员身份运行的应用时，Remote Buddy 也应处于管理员权限。

### 5.3 生效条件

- 修改后必须点击“保存映射”；
- 目标 EXE 路径必须存在，或其应用窗口仍在运行；
- 安全软件、反作弊程序或系统前台锁定策略仍可能阻止切换；
- 被切换的应用不能处于“拒绝激活”的系统状态。

## 6. 语音输入

### 6.1 链路

```text
遥控器语音键
  → 输入法语音快捷键
  → ATVV Control
  → 遥控器麦克风音频
  → IMA ADPCM 解码
  → 16 kHz PCM
  → CABLE Input
  → VB-CABLE 虚拟环回
  → CABLE Output
  → 输入法语音转文字
```

程序在触发语音时向当前前台应用发送输入法快捷键，同时开始读取 ATVV 音频。输入法从 `CABLE Output` 读取音频并完成识别。

### 6.2 触发模式

| 模式 | 行为 |
| --- | --- |
| 按住说话 | 按住语音键时发送快捷键按下，松开时发送抬起；适合微信输入法的按住说话 |
| 点击切换 | 按一次开始，再按一次结束；适合点击式语音输入 |
| 智能免提 | 短按进入免提，长按结束；支持输入法 AudioStop 后的再次打开和会话时限保护 |

根据输入法行为选择模式。如果按住说话没有结束，优先检查输入法快捷键是否设置为“按住说话”以及全局快捷键是否开启。

### 6.3 音频处理

- 遥控器音频按 ATVV 通知接收；
- IMA ADPCM 解码为 16 kHz 单声道 PCM；
- 输出到用户选择的 `CABLE Input` 播放端点；
- 增益可调，保存后用于后续语音会话；
- 输入法从 `CABLE Output` 录音端点读取；
- 音频只在内存中处理，不写入磁盘。

### 6.4 实时电平

总览页和语音页显示实际采样的音频电平：

- `RMS`：当前音频片段的均方根电平；
- `PEAK`：当前片段峰值；
- 数值使用 dBFS；
- 波形随真实采样变化；
- 松开语音键后停止更新并归零，这是会话结束后的预期行为。

电平显示用于确认遥控器确实在发送音频，不能替代输入法的录音设备配置。

## 7. 窗口、托盘与快捷键

### 7.1 窗口

- 自定义标题栏；
- 拖动移动窗口；
- 双击标题栏最大化/还原；
- 最小化、最大化/还原和关闭按钮；
- 双显示器和不同 DPI 下主动修复 WebView 客户区；
- 最小尺寸 `760 × 560`，窄窗口自动折叠侧栏。

### 7.2 托盘

右键托盘图标可以：

- 查看连接状态和最近按键动作；
- 显示主窗口；
- 打开语音页、按键映射和诊断页；
- 重新连接或断开设备；
- 启用/刷新按键增强；
- 导出诊断；
- 清除最近按键；
- 退出程序。

启用“关闭到托盘”后，点击窗口关闭按钮不会结束后台连接。

### 7.3 页面快捷键

主窗口聚焦时，数字键 `1`–`6` 切换页面，`Esc` 关闭当前提示或取消快捷键录制。

## 8. 管理员权限

默认配置会在手动启动时请求管理员权限，原因包括：

- 切换以管理员身份运行的目标应用；
- 恢复高权限应用窗口；
- 改善某些 Windows 蓝牙驱动和 ETW 配置场景的可靠性。

可在设置中关闭“管理员权限启动”，保存后下次启动生效。也可以在设置页点击“立即以管理员权限重新启动”。

同时开启“开机自动启动”和“管理员权限启动”时，程序会创建当前用户的 Windows 计划任务，让登录启动的实例直接使用最高权限。该方式仍然受 Windows 任务计划程序和企业安全策略约束；手动启动不会绕过 UAC。

“静默启动”只影响开机启动路径：登录后程序直接驻留托盘，手动启动仍显示主窗口。

管理员权限不是绕过系统安全策略的通用手段。即使提权，Windows 仍可能阻止某些前台切换。

## 9. 中英双语与界面

- 默认界面语言为简体中文；
- 设置页提供 `English`；
- 页面标题、按钮、提示、诊断状态和托盘菜单保持同一语言逻辑；
- 遥控器按键名称和协议值保留英文标识，便于与协议文档对应。

## 10. 诊断与可观测性

诊断页显示：

- Windows 蓝牙发现状态；
- BthPort 按键采集状态、完整报告数量、被省略数量；
- ATVV / GATT 连接状态；
- `CABLE Input` 与 `CABLE Output` 是否就绪；
- WebView2 运行信息；
- 最近应用日志；
- 一键导出脱敏配置、系统快照和日志的诊断包。

当 Windows 尚未启用完整 BthPort 载荷时，界面会显示“需要配置”或“等待绑定”，不会把“BLE 已连接”误报为“按键采集已就绪”。

## 11. 性能与发布构建

- 仅构建 x64，避免 32 位目标和兼容分支带来的额外体积；
- Release 使用 fat LTO、`opt-level = 3`、单 codegen unit、`panic = abort` 和符号剥离；
- 使用静态 MSVC 运行库，独立 EXE 不依赖 `VCRUNTIME140.dll`；
- WebView 禁用不需要的后台网络和 GPU 合成特性，降低空闲占用；
- Tauri 前端只加载本地资源，CSP 限制为本地 IPC。

Rust 重构可以降低应用层开销，但不会修复系统驱动、蓝牙中断风暴或其他软件造成的系统卡顿。

## 12. 不属于当前范围

- Windows 32 位系统；
- macOS、Linux、Android 或 iOS；
- 非 G9N9N 遥控器的完整按键协议保证；
- Chromecast 固件升级、配对修复或系统级蓝牙驱动修复；
- 自带语音识别模型；
- 云端账号、同步、遥测或远程控制。
