# Remote Buddy v0.3.0

本次更新增加管理员权限开机启动与静默托盘启动，并保留 v0.2.1 的蓝牙连接保活和 Intel 蓝牙兼容修复。

## 本次更新

### 登录后以管理员权限启动

- 在“设置 → 启动与连接”中开启“开机自动启动”和“管理员权限启动”后，Remote Buddy 会创建名为 `Remote Buddy` 的 Windows 计划任务。
- 计划任务仅在当前 Windows 用户登录时触发，并使用“最高权限运行”，因此登录启动不需要再次确认 UAC。
- 任务允许在电池供电时启动，登录触发被错过时会尽快补启动，并且不设置执行时长上限。
- 手动双击程序仍按设置请求 UAC；计划任务不会改变 Windows 对普通程序启动的限制。
- 关闭“管理员权限启动”后，开机启动回退到当前用户启动项。
- 关闭“开机自动启动”并保存，会同时删除计划任务和当前用户启动项。

### 静默启动

- 新增“静默启动”开关。开启后，登录启动只显示系统托盘图标，不弹出主窗口。
- 从桌面或开始菜单手动启动时仍正常显示主窗口。
- 主窗口默认在创建时隐藏，只有在非静默启动路径才主动显示，避免登录时短暂闪出空窗口。

### 可靠性与兼容

- 保存设置时同步更新开机启动；如果计划任务创建失败，设置页会显示具体原因。
- 兼容清理旧版 `tauri-plugin-autostart` 留下的启动值。
- 提权重启会保留 `--autostart` 和 `--silent` 参数，避免登录实例因 UAC 重新启动后意外弹出窗口。
- 移除 `tauri-plugin-autostart` 依赖，减少一个开机启动插件及其传递依赖。

## 使用方式

1. 安装并启动 Remote Buddy；
2. 打开“设置”；
3. 开启“开机自动启动”；
4. 如需登录后直接获得管理员权限，保持“管理员权限启动”开启，并确保当前实例已提权；
5. 如需登录后只驻留托盘，开启“静默启动”；
6. 点击“保存设置”。

如果设置页提示当前不是管理员权限，请先点击“立即以管理员权限重新启动”，然后在 UAC 中选择“是”，再保存一次设置。

## 卸载与清理

- 在设置中关闭“开机自动启动”并保存，会删除计划任务和当前用户启动项；
- 卸载安装版也会由卸载程序清理安装目录；
- 如企业策略残留计划任务，可在 Windows“任务计划程序”中删除 `Remote Buddy` 任务。

## 安装

推荐下载并运行：

```text
Remote-Buddy_0.3.0_x64-setup.exe
```

独立版：

```text
remote-buddy-desktop.exe
```

安装版默认安装到 `C:\Program Files\Remote Buddy`，需要管理员权限，并内嵌 WebView2 静默引导程序。独立版要求系统已安装 WebView2。

## 从旧版本升级

1. 关闭正在运行的 Remote Buddy；
2. 运行新版安装包并同意 UAC；
3. 安装器会保留配置并自动迁移；
4. 启动新版，检查“设置”中的开机启动选项；
5. 如旧版曾启用开机启动，建议保存一次设置，让新实现重建启动项。

## 系统要求

- Windows 10 19041+ 或 Windows 11；
- 仅 x64；
- WebView2；
- 语音功能需要 VB-CABLE 和受支持的输入法；
- 创建管理员开机启动任务需要当前进程具有管理员权限。

## 已知限制

- 管理员开机启动依赖 Windows 计划任务；企业安全策略、组策略或安全软件可能禁止创建或运行该任务。
- 计划任务在用户登录后触发，不是 Windows 启动前的系统服务。
- 手动启动仍可能触发 UAC；这是 Windows 的权限边界，不属于绕过范围。
- 当前安装包未签名，SmartScreen 可能提示未知发布者。
- 普通实体按键首次仍需按诊断页说明配置 BthPort ETW 并重新加载蓝牙。
