# 用户手册

本文面向普通用户，按“安装 → 配对 → 连接 → 启用按键 → 配置映射 → 配置语音”的顺序说明。

## 1. 安装

### 1.1 推荐：NSIS 安装包

从 [GitHub Releases](https://github.com/jimmieyangcsjs/remote-buddy-rust/releases/latest) 下载：

```text
Remote-Buddy_0.2.1_x64-setup.exe
```

双击安装。安装程序采用计算机范围安装，默认路径为 `C:\Program Files\Remote Buddy`，需要同意 UAC 管理员权限。若检测到旧版按用户安装，会先调用旧卸载程序清理副本，再安装到新目录。安装包内嵌 WebView2 静默引导程序；若系统没有 WebView2，安装过程中可能需要联网下载。

### 1.2 独立 EXE

也可以直接运行：

```text
remote-buddy-desktop.exe
```

独立版要求电脑已安装 Microsoft Edge WebView2 Runtime。Windows 11 和多数已更新的 Windows 10 电脑通常已经具备。

### 1.3 首次启动权限

默认设置会请求管理员权限。Windows 会显示 UAC 对话框：

- 选择“是”：以管理员权限运行，应用切换和部分蓝牙配置更可靠；
- 选择“否”：程序可能仍可运行，但切换高权限应用或写入按键增强配置时可能失败。

如果不需要开机提权，可在“设置”中关闭“启动时请求管理员权限”，保存后下次启动生效。

## 2. 配对并连接遥控器

### 2.1 在 Windows 中配对

1. 打开“设置 → 蓝牙和其他设备”；
2. 开启蓝牙；
3. 点击“添加设备”；
4. 选择 `Chromecast Remote`；
5. 按遥控器上的按键唤醒设备；
6. 完成配对，确认 Windows 显示设备已连接。

### 2.2 在 Remote Buddy 中导入

1. 启动 Remote Buddy；
2. 打开“设备”页；
3. 如果设备已自动出现，直接选中它；
4. 如果列表为空，点击“扫描 Windows 设备”；
5. 在已保存设备中选中 `Chromecast Remote`；
6. 点击“连接设备”。

连接成功时，总览页会显示设备名称、蓝牙地址和“已连接”。蓝牙地址属于本机信息，不要在不脱敏的截图中公开。

### 2.3 自动重连

程序在后台监督连接。连接建立后会优先启用 Windows GATT 保活，不再周期性断开重连，也不在连接成功后反复探测 GATT。

如果稳定连接超过 60 秒后意外断开，程序最多执行一次受控恢复；恢复失败会停止自动尝试，等待你手动重连。首次连接失败或连接在稳定前反复中断时也不会无限重试，避免拖累同一适配器上的蓝牙键鼠。

如果你点击了“断开”，自动重连会停止，必须手动点击“连接设备”。这是为了避免用户主动断开后又被后台恢复。

## 3. 启用实体按键

Windows 的 BthPort ETW 默认只输出蓝牙事件头，不提供遥控器普通按键的完整 8 字节报告。因此首次使用需要一次性配置。

### 3.1 操作步骤

1. 打开 Remote Buddy 的“诊断”页；
2. 找到“实体按键需要启用一次蓝牙报告增强”；
3. 点击“启用按键增强”；
4. 在 UAC 中选择“是”；
5. 等待提示配置完成；
6. 关闭并重新打开 Windows 蓝牙，或重启电脑；
7. 重新启动 Remote Buddy；
8. 回到总览页，按遥控器方向键测试虚拟按键是否点亮。

### 3.2 写入的本机配置

程序会请求管理员权限，在以下注册表位置写入：

```text
HKLM\SYSTEM\CurrentControlSet\Services\BthPort\Parameters
  EtwLogSensitiveData = 1
  MaxEtwBytes = 1024
  EtwDropLargeEvents = 0
```

这些值位于本机蓝牙驱动参数中，用于向本机 ETW 会话提供诊断报告。程序不会静默修改注册表，也不会把内容上传。

启用前，程序会把你原有的值备份到 `%APPDATA%\RemoteBuddy\capture-profile.backup.json`。这三个值是**适配器级**设置，同一蓝牙适配器上的鼠标、键盘也会受影响。部分 Intel 蓝牙驱动在 Windows 11 上可能因此出现设备断连、驱动告警或快速重连；遇到这种情况请按 10.3 节恢复。

### 3.3 状态判断

| 诊断状态 | 含义 | 下一步 |
| --- | --- | --- |
| 需要配置 | 尚未写入增强参数 | 点击“启用按键增强” |
| 等待蓝牙重新加载 | 参数已写入，驱动尚未重载 | 关闭/打开蓝牙或重启 |
| 等待绑定 | ETW 已运行，但尚未绑定当前设备 | 确认设备已连接，按一个遥控器按键 |
| 已就绪 | ETW 已绑定并收到完整报告 | 正常使用 |
| 不可用 | ETW 启动失败 | 查看日志，确认权限和安全软件限制 |

## 4. 配置按键映射

打开“按键映射”页，左侧是虚拟遥控器，右侧是当前按键的动作。

### 4.1 选择按键

直接点击虚拟遥控器上的目标按键。被选中的按键会高亮，右侧标题显示按键名称。

### 4.2 配置单击、双击和长按

每个按键有三组独立动作：

1. **单击**：短按一次；
2. **双击**：在约 350 ms 内按两次；
3. **长按**：按住约 700 ms。

如果双击设置为“无动作”，单击会立即触发。设置双击动作后，单击需要等待双击判定窗口结束。

### 4.3 设置快捷键

1. 动作类型选择“快捷键”；
2. 点击快捷键输入框；
3. 直接按下目标组合键；
4. 输入框显示规范化结果；
5. 按 `Esc` 取消录制。

例如：

```text
Ctrl+Shift+F8
Alt+Tab
Win+E
MediaPlayPause
```

### 4.4 设置文本

动作类型选择“文本”，输入要发送的内容。触发时会向当前前台窗口发送文本。

不要在文本动作中保存密码、令牌或其他敏感信息，因为配置文件以本机明文形式保存。

### 4.5 设置媒体键

动作类型选择“媒体键”，然后选择：

- 音量加；
- 音量减；
- 静音；
- 播放/暂停。

### 4.6 连续重复

方向键和音量键可以选择“连续重复”，并设置间隔。适合长按移动和连续调音量。

### 4.7 长按行为

快捷键和媒体键支持两种长按行为：

- **约 700 ms 触发一次**：达到阈值后执行一次，继续按住不重复；
- **按住保持，松开释放**：达到阈值后发送按下，直到遥控器松开才发送抬起。

对讲、游戏或需要持续按住的快捷键应选择“按住保持”。普通开关型动作建议保持“触发一次”。

### 4.8 保存与恢复

- 修改后点击“保存映射”；
- 保存成功后，新动作立即生效；
- 点击“恢复默认”只恢复当前遥控器的默认映射。

## 5. 设置切换应用

### 5.1 从运行应用中选择

1. 选择一个按键；
2. 将单击、双击或长按的动作类型设为“切换应用”；
3. 点击应用选择框；
4. 从列表中选中目标应用；
5. 点击“保存映射”。

列表来自当前可见的 Windows 应用窗口。程序不会上传应用列表或窗口标题。

### 5.2 手动填写 EXE

如果目标应用没有可见窗口，可以填写完整 EXE 路径，例如：

```text
C:\Program Files\Example\Example.exe
```

目标应用未运行时，程序会启动该路径；已经运行时，会优先激活已有窗口。

### 5.3 保存后仍启动旧应用

按顺序检查：

1. 是否点击了“保存映射”并看到成功提示；
2. 动作名称和路径是否确实指向目标应用；
3. 目标应用是否以另一个 EXE 路径运行；
4. 目标应用是否以管理员身份运行；
5. 是否需要让 Remote Buddy 也以管理员身份运行；
6. 是否被 Magpie、远程桌面、安全软件或全屏覆盖层阻止；
7. 打开诊断页，导出日志并查看最近的切换错误。

## 6. 配置语音输入

语音链路需要 VB-CABLE、Remote Buddy 和输入法三方配合。

### 6.1 安装 VB-CABLE

1. 从 [VB-Audio 官方页面](https://vb-audio.com/Cable/) 下载；
2. 完整解压；
3. 右键 `VBCABLE_Setup_x64.exe`，选择“以管理员身份运行”；
4. 点击 `Install Driver`；
5. 按提示重启 Windows；
6. 在“声音设置 → 所有声音设备”确认存在：
   - `CABLE Input`（播放端点）；
   - `CABLE Output`（录音端点）。

不要将 `CABLE Input` 设为 Windows 默认播放设备，否则其他应用的日常声音也会进入虚拟麦克风。

### 6.2 配置 Remote Buddy

1. 打开“语音”页；
2. “输出到 CABLE Input”选择 `CABLE Input` 或对应的 VB-Audio 播放端点；
3. “输入法读取 CABLE Output”选择 `CABLE Output`；
4. 点击保存或“重新检测”；
5. 确认 `CABLE Input` 和 `CABLE Output` 都显示已就绪；
6. 点击“测试输出”，确认输入法能够收到测试音频。

### 6.3 配置微信输入法

不同版本界面文字可能略有差异，核心设置如下：

1. 打开微信输入法设置；
2. 开启语音输入；
3. 开启“快捷键全局生效”；
4. 触发方式选择“按住说话”；
5. 快捷键设置为与 Remote Buddy 完全一致；
6. 麦克风选择 `CABLE Output`；
7. 保存设置。

如果输入法只允许其内置快捷键，请让两边保持一致；不要只修改其中一边。

### 6.4 测试

1. 打开一个可输入文本的窗口；
2. 按住遥控器语音键；
3. 对着遥控器说话；
4. 观察总览或语音页的 RMS / PEAK 是否变化；
5. 松开语音键；
6. 等待输入法出现识别结果。

如果电平有变化但没有文字：

- 输入法麦克风没有选择 `CABLE Output`；
- 输入法快捷键不一致；
- 输入法没有开启全局快捷键；
- 触发模式与输入法行为不匹配。

如果电平没有变化：

- 遥控器语音键没有触发 ATVV；
- 设备连接已断开；
- 选择了错误的语音触发模式；
- 蓝牙驱动或遥控器麦克风状态异常。

### 6.5 音频电平归零

松开语音键后 RMS / PEAK 归零是正常行为。程序只在语音会话期间接收音频，不会继续显示上一次电平。

## 7. 托盘和后台运行

### 7.1 关闭到托盘

在“设置”中开启“关闭到托盘”。之后点击窗口关闭按钮只会隐藏窗口，应用继续：

- 保持设备连接；
- 执行自动重连；
- 接收遥控器按键；
- 在托盘中显示状态。

### 7.2 托盘菜单

右键托盘图标可执行：

- 显示主窗口；
- 打开语音页；
- 打开按键映射；
- 打开诊断页；
- 重新连接；
- 断开；
- 启用/刷新按键增强；
- 导出诊断；
- 清除最近按键；
- 退出 Remote Buddy。

### 7.3 真正退出

如果开启“关闭到托盘”，关闭窗口不会退出进程。需要从托盘菜单选择“退出 Remote Buddy”。

## 8. 管理员权限

需要管理员权限的典型场景：

- 切换以管理员身份运行的 ChatGPT、Argus 或其他应用；
- 恢复被系统保护的高权限窗口；
- 写入按键增强所需的 BthPort 配置。

切换方式：

1. 打开“设置”；
2. 找到“管理员权限”；
3. 点击“立即以管理员权限重新启动”；
4. 在 UAC 中选择“是”。

如果希望以后自动请求权限，开启“启动时请求管理员权限”并保存。

## 9. 语言与开机启动

- 在“设置 → 界面语言”选择简体中文或 English；
- 语言设置保存后长期生效；
- “开机自动启动”使用 Windows 当前用户登录启动项；
- 开机启动不会绕过 UAC；若启用了管理员启动，登录时仍可能出现确认提示。

## 10. 数据位置与卸载

### 10.1 配置和日志

```text
%APPDATA%\RemoteBuddy\config.json
%APPDATA%\RemoteBuddy\config.backup.json
%APPDATA%\RemoteBuddy\logs\rust-app.log
%APPDATA%\RemoteBuddy\diagnostics\
```

### 10.2 卸载

在 Windows“设置 → 应用 → 已安装的应用”中找到 Remote Buddy 并卸载。

卸载程序通常不会自动删除用户配置。如果不再使用，可手动删除 `%APPDATA%\RemoteBuddy`。删除前请确认其中没有还需要保留的配置或诊断记录。

### 10.3 恢复 BthPort 参数

推荐在 Remote Buddy 的“诊断”页点击“恢复蓝牙默认设置”，或在托盘右键菜单选择同一操作。程序会请求管理员权限，并按首次启用前保存的备份精确恢复 `EtwLogSensitiveData`、`MaxEtwBytes` 和 `EtwDropLargeEvents`；如果原值本来不存在，会删除对应值。

如果没有可用备份，程序只会删除与自身已知写入完全一致的值，不会改动其他软件或驱动设置的数值。恢复后请重启电脑，再确认蓝牙鼠标和键盘是否稳定。

只有需要手动核对时才查看以下位置：

```text
HKLM\SYSTEM\CurrentControlSet\Services\BthPort\Parameters
  EtwLogSensitiveData
  MaxEtwBytes
  EtwDropLargeEvents
```

修改注册表前建议先导出备份。不同 Windows 版本和蓝牙驱动可能使用不同默认值，不要在不确定时随意覆盖。恢复默认值后，普通遥控器按键可能暂时不可用；需要时可在确认蓝牙键鼠稳定后重新启用按键增强。

## 11. 常见问题

### 已配对但程序找不到设备

- 按遥控器按键唤醒；
- 确认 Windows 蓝牙设置显示设备已连接；
- 点击“扫描 Windows 设备”；
- 关闭后重新打开蓝牙；
- 重启 Remote Buddy；
- 删除 Windows 中的旧配对记录后重新配对。

### 已连接但普通按键不亮

- 检查诊断页“按键采集”是否为“已就绪”；
- 若显示“需要配置”，完成按键增强；
- 若显示“等待蓝牙重新加载”，关闭/打开蓝牙或重启；
- 若显示“等待绑定”，按一个遥控器按键触发绑定；
- 查看完整报告计数是否增加。

### 某些按键没有反应

- 检查对应按键是否设置为“无动作”；
- 检查单击/双击/长按是否选错；
- 若设置了双击，单击需要等待判定窗口；
- 测试时将动作改成简单快捷键，排除目标应用问题；
- 导出诊断包查看报告是否到达。

### 最小化后失效

新版把设备连接和窗口显示解耦，关闭到托盘后仍应保持连接。若仍失效：

- 确认没有选择托盘菜单中的“断开”；
- 检查 Windows 是否因省电策略断开蓝牙；
- 在设备页点击“连接设备”；
- 查看日志中的 supervisor 和 ETW 状态；
- 尝试关闭 Windows 蓝牙省电选项。

### 双显示器最大化异常

该问题已在 `0.2.0` 中加入窗口布局修复：

- 窗口最大化/还原后主动对齐 WebView；
- 处理移动、缩放和 DPI 变化；
- 双击标题栏执行真正的最大化/还原切换。

如果仍出现异常，请记录显示器排列、缩放比例、Windows 版本和复现步骤。

### 应用切换失败

- 先保存映射；
- 确认目标应用路径；
- 以管理员权限运行 Remote Buddy；
- 关闭 Magpie 等覆盖层后再试；
- 查看诊断日志中的 `focus` 或 `foreground` 错误。

### 安装或启动被 SmartScreen 拦截

当前发布包未签名，可能出现“未知发布者”。请从官方 Releases 页面下载并校验 SHA-256。不要从第三方网盘或转载站点下载。
